# Tolokabot

Telegram-бот для заявок на запрошення на зустріч будівельної спільноти
10 жовтня в ресторанному комплексі «Вікторія» у Київській області.

Після `/start` користувач вводить ім’я, а потім номер телефону вручну.
Заявка надсилається адміністратору разом із Telegram-профілем користувача.
Подяка надсилається після успішного надсилання заявки адміністратору.

## Запуск

Зберігаються Python 3.10 та основні версії залежностей.
У `requirements.txt` також зафіксовано сумісний `setuptools`, потрібний
для APScheduler зі складу `python-telegram-bot==13.15`.
Потрібні змінні середовища:

- `TOKEN` — токен наявного Telegram-бота.
- `ADMIN_CHAT_ID` — числовий ID чату для отримання заявок.

Для нового отримувача заявок установіть у змінних сервісу Railway:

```text
ADMIN_CHAT_ID=456346101
```

Новий отримувач має відкрити чат із ботом і надіслати `/start`,
щоб бот міг надсилати йому заявки.

Команда запуску: `python bot.py` (зазначена також у `Procfile`).
`CHANNEL_USERNAME` більше не використовується.
Для бота з polling запускайте лише один екземпляр одночасно.

## Перевірка

Після встановлення залежностей: `python -m unittest discover -s tests -v`.
Перевірки використовують імітацію Telegram і не запускають живий бот.
